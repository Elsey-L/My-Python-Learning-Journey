# 星座星象分类统计器


## 项目简介

这是一个基于 Python 的星座星象分类与统计工具。

只知道星座不清楚对应的星象？没关系！用户可以输入一个至多个星座名称，程序会自动将其归类到对应的四大星象（水象、风象、土象、火象），并统计各星象的出现次数。

**主要功能：**
- 星座到星象的自动分类
- 星象去重显示
- 各星象数量统计

## 项目文件说明

- `平时作业2代码.py`: 星座星象分类统计器的完整 Python 源代码。

## 代码说明

- 数据输入与定义模块-定义星座与星象的对应关系并转换输入信息为列表

- 数据处理模块-循环实现星座分类数据转换

- 统计分析模块-识别星象类型并用count_signs函数统计频次
